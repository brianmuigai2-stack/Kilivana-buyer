# Product and banner images

The app bundles real produce photographs in `app/src/main/res/drawable-nodpi/`. Product images are 800x800 square JPEGs. Banner images are 1200x500 JPEGs.

Overwrite the file with the same name and extension. Do not add a second file with the same name in a different format, or the build will fail with a duplicate resource error.
